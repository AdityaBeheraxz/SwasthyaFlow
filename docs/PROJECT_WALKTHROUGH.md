# Project walkthrough

1. Sign in with an authorized Health Worker or Nurse account and record consent.
2. Enter the patient-reported concern in the language used by the patient.
3. Upload a genuine, de-identified report image that the project is authorized to process.
4. Run OCR, compare every extracted value with the original file, correct mistakes, and confirm the reviewed text.
5. Generate the structured note and inspect each source, missing-information item, follow-up question, and rule explanation.
6. Sign in as a Medical Officer to edit the summary, approve the record, or record a justified escalation or downgrade.
7. Prepare the referral summary and inspect the audit history.

Use only de-identified records approved for the environment. The walkthrough exercises the real data path; it does not establish clinical performance.
